# Exercise illustrations

The files in this folder are from the **RepDB Free Exercise Dataset**:

- Source: https://repdb.co/ · https://github.com/RepDB/exercise-dataset
- License: free tier, in-app use with visible attribution
- Required attribution: **"Exercise data by RepDB (repdb.co)"**

Only the 512×512 WebP stills needed by the Gym Plan B demo are bundled here
(Test Set + candidates). The full dataset is not redistributed. Files are
renamed to exercise slugs for this app; the original RepDB exercise ids are
listed in the project's import notes.

Paid `premium-samples/` assets were not used.
